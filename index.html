Для команды Tribute: Это информационная страница о продукте. Сама платформа TransitHub является закрытым сервисом — клиентский портал доступен только по персональным ссылкам для авторизованных пользователей. Публичный доступ к панели управления отсутствует.
TransitHub
VPN Subscription Aggregator
BETA

📦 Что это

TransitHub — платформа для управления VPN-подписками. Агрегирует несколько VPN-источников в единую систему с клиентским порталом, админ-панелью и автоматическим управлением доступом.

⚡ Возможности

🔗
Единая ссылка
Клиент получает персональную ссылку для настройки VPN-клиента за один клик
📊
Статистика
Мониторинг трафика, использование по дням, лимиты
🌍
Выбор серверов
Список доступных серверов с пингом и статусом онлайн
🔄
Автопродление
Автоматическое продление подписки при оплате через Tribute
📱
Мобильный портал
Адаптивный интерфейс, работает на любых устройствах
🤖
Telegram интеграция
Уведомления о статусе подписки через Telegram-бота

🔄 Как работает оплата

Клиент нажимает «Оплатить»
В клиентском портале выбирает период и переходит к оплате
Оплата через Tribute
Банковские карты (Visa/MC/МИР), СБП, Telegram Stars
Вебхук на сервер
Tribute отправляет POST-запрос с информацией об оплате
Подписка продлевается
Сервер автоматически продлевает доступ и уведомляет клиента
